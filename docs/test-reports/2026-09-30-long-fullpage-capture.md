# 긴 페이지 전체 캡쳐 한도 안내 — 테스트 체크리스트 (v1.1.3)

## 준비
1. 이 브랜치(`claude/long-screen-capture-fix-0465eb`)를 받아 `chrome://extensions` → 개발자 모드 → "압축해제된 확장 프로그램을 로드합니다"로 저장소 루트 폴더를 선택
   (기존 스위캡쳐는 꺼두기 — 단축키/우클릭 메뉴가 겹침)
2. 툴바 아이콘 팝업 제목 오른쪽에 **v1.1.3** 이 보이면 새 버전 로드 완료

## 테스트 페이지
- 긴 페이지(약 60화면, 세로 약 54,000px): https://raw.githack.com/loreenkim0301/swycapture/claude/long-screen-capture-fix-0465eb/docs/test-pages/long-page-test.html
- 원본 파일: [docs/test-pages/long-page-test.html](../test-pages/long-page-test.html)

## 확인 항목
- [ ] 팝업 제목 오른쪽에 `v1.1.3` 표시
- [ ] 캡쳐 후 열리는 주석 편집기 상단 배지도 `v1.1.3`
- [ ] 테스트 페이지 맨 위에서 "전체 페이지 캡쳐" → 한도 안내 팝업이 뜸
  - 문구: "이 페이지는 약 N화면 길이에요. 이미지(PNG)·PDF로는 원본 화질 기준 약 M화면까지만 저장이 가능합니다."
  - 선택지: "처음부터 약 M화면까지 캡쳐"(추천) / 취소 — 맨 위에서는 "지금 보는 위치부터"는 안 보이는 게 정상
- [ ] "처음부터" 선택 → 1구간부터 이어진 이미지가 편집기에 열림, 완료 알림에 "전체 약 N화면 중 약 M화면" 표시
- [ ] 페이지 중간(예: 30구간)으로 스크롤 후 "전체 페이지 캡쳐" → "지금 보는 위치부터" 선택지가 보임 → 선택 시 그 구간부터 캡쳐됨
- [ ] 취소 / Esc / 바깥 클릭 → 팝업이 닫히고 아무것도 캡쳐되지 않음
- [ ] 팝업을 띄운 채 30초 이상 기다렸다가 선택해도 캡쳐가 진행됨
- [ ] 캡쳐 이미지에 안내 팝업이 찍혀 있지 않음
- [ ] 편집기에서 PDF로 저장 / PNG로 저장이 정상 동작
- [ ] 짧은 일반 페이지의 전체 페이지 캡쳐는 팝업 없이 예전처럼 바로 진행
