# 스위캡쳐 (SwyCapture) v1.1.0

브라우저 화면을 캡쳐한 즉시, 이미지 위를 클릭해 핀을 찍고 댓글을 붙인 뒤
**HTML / PNG / PDF**로 저장하는 크롬 확장입니다.

## 설치 (개발자 모드, 언패킹)

1. Chrome 주소창에 `chrome://extensions` 입력
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭 (이미 설치되어 있다면 새로고침 ↻)
4. 이 폴더(`swyshot-extension`) 선택

## 사용법 — 캡쳐 3가지 모드

**확장 아이콘을 클릭하면 메뉴가 뜨고, 원하는 모드를 선택하는 즉시 촬영됩니다.**
(페이지 우클릭 → "스위캡쳐로 캡쳐" 서브메뉴에서도 동일하게 선택 가능)

1. **현재 화면 캡쳐** — 지금 보이는 화면 그대로 (기존과 동일, 단축키 `Cmd/Ctrl+Shift+S`)
2. **전체 페이지 캡쳐** — 페이지를 끝까지 스크롤하며 조각 캡쳐를 이어붙여 스크롤 전체를 하나의 이미지로 저장
3. **영역 선택 캡쳐** — 클릭 즉시 화면에 반투명 오버레이가 뜨고, 원하는 영역을 드래그하면 그 부분만 잘라서 캡쳐 (Esc로 취소)

캡쳐 후 흐름은 기존과 동일합니다: 새 탭에서 이미지 클릭 → 댓글 핀 추가 → 우측 상단 HTML/PDF/PNG 중 원하는 형식으로 저장.

## v1.1.0 업데이트

- 첫 댓글을 "추가" 버튼으로 확정하면 "댓글에 이름을 남길까요?" 창이 한 번 뜹니다 — 이름을 입력해 저장하거나 "이름 설정 안 함"을 선택할 수 있습니다. 이후 댓글부터는 다시 묻지 않습니다.
- 헤더의 "이름 설정" 버튼으로 언제든 이름을 다시 설정/변경 가능 (설정은 저장되어 다음 캡쳐에도 유지됨)
- 이름을 설정하면 댓글 목록·핀 툴팁·HTML/PNG 저장 결과에 작성자 이름이 함께 표시됨
- 한글/영문 2개 언어를 지원합니다 (Chrome 표준 다국어 방식). 크롬 브라우저의 표시 언어에 따라 자동으로 전환되며, 크롬 웹 스토어에 등록 시 사용자 언어에 맞는 이름/설명이 노출됩니다.

## v1.0.0 업데이트

- 캡쳐 방식을 3가지(현재 화면 / 전체 페이지 / 영역 선택)로 확장
- 툴바 아이콘 클릭 시 팝업 메뉴에서 바로 모드 선택 → 즉시 촬영
- 우클릭 컨텍스트 메뉴도 3개 서브메뉴로 확장
- 단축키는 "현재 화면"에만 기본 배정(`Cmd/Ctrl+Shift+S`). 전체 페이지/영역 선택 단축키는 `chrome://extensions/shortcuts`에서 직접 배정 가능

## 이전 업데이트 이력

- 우측 상단에 "PDF로 저장" 버튼 추가 (브라우저 인쇄 다이얼로그 → "PDF로 저장" 선택). 인쇄 화면은 버튼·연결선 등을 숨기지 않고 화면 그대로 인쇄
- 핀 클릭 시 오른쪽 댓글 목록과 계단식(직각) 연결선으로 매칭 표시, 핀 드래그 이동, 핀 기본 반투명(원본 이미지 가시성 우선)
- HTML/PNG 저장 시 우측에 댓글 목록 패널을 항상 표시 (에디터와 동일한 레이아웃)

## 알려진 제한 (테스트 버전 범위)

- **전체 페이지 캡쳐**: 스크롤하며 여러 장을 이어붙이는 방식이라 몇 초 걸릴 수 있고, `position: sticky`/`fixed` 헤더가 있는 페이지는 이미지 중간에 여러 번 겹쳐 나올 수 있습니다. 또한 매우 긴 페이지(대략 3만 px 초과)는 캔버스 크기 제한으로 캡쳐가 거부됩니다.
- **영역 선택 캡쳐**: 현재 화면(스크롤 안 된 뷰포트) 안에서만 영역을 선택할 수 있습니다 — 스크롤하면서 영역을 넘기는 것은 지원하지 않습니다.
- `chrome://`, 크롬 웹스토어 등 확장 프로그램이 접근할 수 없는 페이지에서는 오버레이 삽입/스크립트 실행이 되지 않아 전체 페이지·영역 선택 캡쳐가 동작하지 않을 수 있습니다 (현재 화면 캡쳐는 대체로 가능).
- 저장된 `.html` 파일을 다시 열어 댓글을 추가/수정하는 기능은 아직 없습니다 (내보내면 뷰어 전용)

## 이 파일에 대해

이 코드는 2026-08-14 대화("맥북 스크린샷에 스위노트 기능 추가")에서 실제로 만들었던 v1.0.0의
편집 이력(각 str_replace/재작성 단계)을 그대로 추적해 재구성한 것입니다. 원본 세션의 임시
컨테이너는 이미 종료되어 직접 복사할 수 없었고, 대화 로그를 근거로 다시 조립했습니다.
클로드코드로 넘겨 이어서 작업하기 전에, 실제로 `chrome://extensions`에 로드해서
캡쳐 3종 → 댓글 → HTML/PNG/PDF 저장까지 한 번 돌려보고 이상 없는지 확인하는 걸 권합니다.
