스위캡쳐(SwyCapture) 개인정보처리방침

최종 업데이트 · 2026-09-09 (v1.1.0 기준)

결론부터 말씀드리면 — 스위캡쳐는 여러분의 화면 캡쳐 이미지나 댓글을 저장하거나 전송하는 서버를 갖고 있지 않습니다. 모든 데이터는 사용하시는 브라우저 안에만 남습니다.

1. 수집하는 정보

스위캡쳐는 별도의 서버를 운영하지 않으며, 사용자의 개인정보를 수집·저장·전송하지 않습니다. 캡쳐한 화면 이미지, 댓글 내용, 설정한 이름은 모두 사용자의 브라우저(Chrome storage)에만 저장되고, 확장 개발자를 포함한 어떤 외부 서버로도 전송되지 않습니다.

HTML로 저장하기를 실행하면 이미지와 댓글이 담긴 파일 하나가 사용자의 컴퓨터에 다운로드될 뿐이며, 이 과정에서도 외부 업로드는 발생하지 않습니다.

2. 요청하는 권한과 이유

권한사용 목적
activeTab사용자가 아이콘을 클릭하거나 단축키를 눌렀을 때, 현재 탭의 화면을 캡쳐하기 위해 사용합니다.
scripting전체 페이지 캡쳐 시 스크롤 위치를 옮기고, 영역 선택 캡쳐 시 선택 오버레이를 페이지에 표시하기 위해 사용합니다.
storage캡쳐한 이미지·댓글·설정한 이름을 브라우저 로컬 저장소에 임시 보관하기 위해 사용합니다.
downloads사용자가 "HTML/PNG로 저장" 버튼을 눌렀을 때 결과 파일을 컴퓨터에 내려받기 위해 사용합니다.
host_permissions (모든 사이트)어떤 웹페이지에서도 캡쳐 기능을 사용할 수 있도록 하기 위해 필요합니다. 페이지 내용을 읽거나 서버로 전송하지 않습니다.
contextMenus우클릭 메뉴에 "스위캡쳐로 캡쳐" 항목을 추가하기 위해 사용합니다.

3. 제3자 제공 및 광고

스위캡쳐는 어떤 형태의 사용자 데이터도 제3자에게 제공, 판매, 공유하지 않습니다. 광고 SDK, 분석 도구(애널리틱스), 트래킹 스크립트를 포함하지 않습니다.

4. 데이터 보관 및 삭제

캡쳐 이미지와 댓글은 새로운 캡쳐를 시작하면 이전 데이터가 교체되며, 설정한 이름은 확장을 삭제하거나 chrome://extensions에서 데이터를 지울 때까지 브라우저에 남습니다. 직접 삭제를 원하시면 확장 프로그램을 제거하는 것으로 모든 저장 데이터가 함께 삭제됩니다.

5. 정책 변경

이 방침이 변경되는 경우 이 페이지에 최신 내용을 반영하고 상단의 최종 업데이트 날짜를 갱신합니다.
